API Client workspace

Local, reusable requests

Import Postman Collection v2.1 and environment files in the browser. Unsupported behavior is called out before you run anything.
Collections, nested folders, saved requests, variables and named environments persist in origin-scoped IndexedDB.
Collection, folder and request auth can inherit or override Bearer, Basic, API keys and OAuth 2.0.
Run a collection or folder in saved order. See progress, status, timing, tests and script or transport errors for each request.
Runs are sequential, so variable changes carry into later requests. Stop aborts the active fetch and leaves the remaining requests untouched.
Pre-request and test scripts include flex.* IntelliSense, signatures, variable names and assertion help.
History groups collection runs and lets you search, inspect responses and tests, replay requests or delete entries.
History keeps up to 100 entries. Stored response bodies are capped at 256 KiB.
Local data
Saved auth values, variables, scripts and History are stored as entered and are not encrypted. Response History may contain tokens or other sensitive data. Scripts are trusted local JavaScript. Nothing is sent until you run a request.
